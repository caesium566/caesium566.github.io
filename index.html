维护手册

功能

P3 风格个人工作台：今日（每日抽三 × 塔罗，v3.1）/ 成长（五维·月相·成就，v3.2）/ 活动（游戏日历甘特图）/ 预算（指令单看板 + 本周纪律）+ 老工具入口抽屉。

数据存储

真身在浏览器 localStorage：cal_done_v1 / cal_custom_v1 / cal_import_v1 / cal_hidden_v1 / cal_budget_v1 / cal_gh；velvet_* 段预留。同步走 Private 仓 cal-data 的 data.json（按条目合并），Token 只存本机。公开 events.json 是只读层，不进同步。

使用说明

  • 手机用底部导航切四页；电脑点左上角月相呼出左侧边栏。活动页：月份导航、＋添加、筛选抽屉；删条目用每行悬停的 ×。
  • 预算页：本周纪律条在顶部；「更新数据」粘贴指令单解析（纪律与预算同窗编辑）；锁定项勾选 = 已购入，计入绑定分类。
  • 同步、导入 events.json、本手册都在顶栏「设置」里；变更后 3 秒自动推、前台每 2 分钟轮询拉。

维护要点

  • 预算解析器（bParse 系）与指令单格式是冻结契约，一个字符不改。
  • localStorage 键名勿改；版本号在 <meta name="app-version"> 与顶栏徽标，两处同步 +1。
  • 弹层 z-index 梯度：普通 50、设置 60，新弹层继续 +10。
  • 只庆祝不惩罚：不加扣点/断签/streak；红色仅用于庆祝与预算超支。
