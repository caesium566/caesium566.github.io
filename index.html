维护手册

功能

P3 风格个人工作台：时光（时间线 + 每日抽三计划块 + 计时 + 当日感受 + 待办/工坊维护）/ 成长（五维 Rank，xp 从 md 日志推导，只增不减）/ 活动（游戏日历甘特图）/ 预算（指令单看板 + 本周纪律）+ 老工具入口抽屉。

数据存储

真身在浏览器 localStorage：cal_done_v1 / cal_custom_v1 / cal_import_v1 / cal_hidden_v1 / cal_budget_v1 / cal_gh 与 velvet_* 段（时间线 / 感受 / 计划块 / 时段分类 / md 镜像缓存）。同步走 Private 仓 cal-data：冻结的 data.json（活动/预算）+ velvet/data.json（时光页）+ velvet/0-待办事项.md、velvet/0-工坊.md（ob 镜像，工作台唯一写入端，写前必校验 sha）。Token 只存本机。公开 events.json 是只读层，不进同步。

使用说明

  • 时光页：日期栏 ←→ 翻日（凌晨 4 点切日）；右侧两图标 = 重新抽取 / 维护。每天首次打开自动抽三项落 19:00 计划块（可移除、不留记录），点计划块落定实际起止。右下悬浮钮计时，结束自动成时段卡。关联了待办/工坊的时段，备注即当日日志：保存时自动写进 md，改备注同步改日志（同日整行替换）。
  • 维护弹出页：待办（进行中：新增/完成/删/追加日志）、已完成（档案馆：点开看开始日期与全部日志，可恢复为进行中）、工坊（新增项目/追加日志/删）三栏；全部手术刀式写回 md，不重排全文。
  • 成长页：雷达形状 = 近 30 天各维得分占比，五角数字 = 总 Rank；等级名到 R4 / R7 / R10 才有庆祝章，下一级名未达前显示 ???。
  • 手机用底部导航切四页；电脑点左上角月相呼出左侧边栏。活动页：月份导航、＋添加、筛选抽屉；删条目用每行悬停的 ×。
  • 预算页：本周纪律条在顶部；「更新数据」粘贴指令单解析；锁定项勾选 = 已购入，计入绑定分类。
  • ob 侧：首次在电脑库里跑 python .tools/velvet_sync.py push 初始化镜像，之后日常跑 python .tools/velvet_sync.py 拉取覆盖。

维护要点

  • 预算解析器（bParse 系）与指令单格式是冻结契约，一个字符不改。
  • localStorage 键名勿改；版本号在 <meta name="app-version"> 与顶栏徽标，两处同步 +1。
  • 弹层 z-index 梯度：普通 50、设置 60、维护 70、庆祝 80，新弹层继续 +10。
  • 只庆祝不惩罚：不加扣点/断签/streak；红色仅用于庆祝与预算超支。
  • md 写回前扫描 Token 特征（ghp_ 等），命中直接拒绝。
